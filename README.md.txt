## Purpose
The Storage Estimator is a Python program that calculates
and estimates storage requirements based on user input.
It helps users understand the amount of storage needed
for the given data.

## How to Run
1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

   python storage_estimator.py

## Example Input and Output
Run the program and enter the required input values.
The program will display the estimated storage result.

Example:
Input: Use the values requested by the program.
Output: The estimated storage requirement is displayed.

Note: The exact input and output depend on the values
entered and the calculations in the program.
